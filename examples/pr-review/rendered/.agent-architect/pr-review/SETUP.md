## MCP servers

Nothing below has been installed. Approve each server, then merge the snippet for your harness into the named file (keep existing entries).

- **github** (http) — Read PR details and post the approved review comment. Docs: https://github.com/github/github-mcp-server
  Needs: `GITHUB_TOKEN`

Export these in your shell or secret manager; never paste values into config files:

```bash
export GITHUB_TOKEN=...
```

### claude-code, copilot-cli → `.mcp.json`

```json
{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": {
        "Authorization": "Bearer ${GITHUB_TOKEN}"
      }
    }
  }
}
```

## Run it

- In Claude Code: `/review-pr <PR number or URL>`
- In Copilot CLI: `/fleet Use the /review-pr skill with <PR number or URL>` (fleet runs the agents in parallel)
- In Codex: `$review-pr <PR number or URL>`, or ask Codex to use the review-pr skill
- In Gemini CLI: ask Gemini to use the `review-pr` skill with <PR number or URL>
- In Cursor: `/review-pr <PR number or URL>` in Agent chat
- In OpenCode: ask the agent to use the `review-pr` skill with <PR number or URL>

Start small: one input and a single wave, check the output, then scale up.

Restart the harness (or reload skills/agents) after rendering so it picks up new files.
