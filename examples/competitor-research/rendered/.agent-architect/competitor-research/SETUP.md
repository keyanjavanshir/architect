# Setup: competitor-research

Researches a list of competitors in parallel — one agent per company — and combines the profiles into a single comparison brief with sources. No code involved.

Generated by agent-architect for: claude-code, copilot-cli, codex, gemini-cli, cursor, opencode.
Edit `blueprint.yaml` and re-render instead of editing generated files.

## Run it

- In Claude Code: `/research-competitors <comma-separated company names> [focus, e.g. pricing]`
- In Copilot CLI: `/fleet Use the /research-competitors skill with <comma-separated company names> [focus, e.g. pricing]` (fleet runs the agents in parallel)
- In Codex: `$research-competitors <comma-separated company names> [focus, e.g. pricing]`, or ask Codex to use the research-competitors skill
- In Gemini CLI: ask Gemini to use the `research-competitors` skill with <comma-separated company names> [focus, e.g. pricing]
- In Cursor: `/research-competitors <comma-separated company names> [focus, e.g. pricing]` in Agent chat
- In OpenCode: ask the agent to use the `research-competitors` skill with <comma-separated company names> [focus, e.g. pricing]

Start small: one input and a single wave, check the output, then scale up.

Restart the harness (or reload skills/agents) after rendering so it picks up new files.
